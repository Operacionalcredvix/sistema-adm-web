# Sistema ADM 0.6.2 — Suavização visual e organização das telas

## Objetivo

Reduzir a agressividade visual do sistema e melhorar conforto de leitura.

A ideia não é criar menus novos nem alterar regra de negócio. É fazer as telas atuais ficarem mais calmas, menos cansativas e mais organizadas visualmente.

## Decisões

- Fundo sai do preto absoluto para grafite escuro.
- Cards ficam menos pesados.
- Bordas e sombras ficam mais discretas.
- Amarelo continua como identidade, mas menos saturado.
- Vermelho fica menos agressivo.
- Filtros, chips e badges perdem peso visual.
- Topbar deixa de competir com o conteúdo.
- Loading fica menos brilhante.
- O sistema deve parecer administrativo/profissional, não painel neon.

## O que não muda

- Banco
- Supabase
- Cache
- Regras de alerta
- Anexos
- Menu
- Fluxos principais

## Próximos passos

Depois desta suavização, a próxima etapa deve ser uma revisão tela por tela:

1. Unidades — reduzir card e melhorar lista.
2. Alertas — simplificar filtros e cards.
3. Ficha — compactar cabeçalho e organizar seções.
4. Modais — estruturar campos por grupo.
5. Usuários — trocar linguagem técnica por linguagem de produto.
